# Layout that learns from a designer's drags

> A card-sizing function runs as an exact Handwired neural net. Drag a few cards to the widths you want; three constants learn from the drags, every card at every screen width follows, and nothing ever overflows. A generic net on the same drags does.

Source: https://handwired.wiki/pages/layout.html

<p class="lede">Show the layout what you want with a few drags. The code learns its numbers, and its limits stay exact.</p>
