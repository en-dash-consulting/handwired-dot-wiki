Handwired FAQ

Quick, sourced answers about Handwired. Everything here is drawn from chenglou.me/handwired and the chenglou/handwired repository.

What is Handwired?

Handwired is an open-source project by Cheng Lou that turns regular JavaScript logic into a neural net: no training, exact, yet fully differentiable, and runnable in a browser without a GPU. Programs are written as matrix multiplications and ReLUs over 32-bit floats.

When should I use Handwired?

Use it when you already have readable code with a few constants, some rules that must stay exact, and data that should tune those constants: a search ranking learned from clicks, a layout fitted to a designer's examples, physics fitted to a recording, or a colour theme fitted to a designer's picks that must keep WCAG contrast. Handwired runs the code as an exact, differentiable neural net, so training only moves the numbers and the rules keep holding. If you have no trusted code and lots of data, a regular model is the better tool. See the live ranking demo.

How do I turn JavaScript into a neural network?

With Handwired you rewrite the logic with its builder API (circuit.affine, circuit.reglu, emitCompare, emitSelect and friends), which appends exact operations to a Circuit; the result is a neural net that returns the same answers as your JavaScript. There is no automatic converter: you write builder code once, by hand. See Getting started and the beginner cat lesson.

Who made Handwired?

Cheng Lou, also known for Pretext and React Motion. The code is at github.com/chenglou/handwired under the MIT license.

Is Handwired a JavaScript-to-neural-net compiler?

Not in the sense of parsing your source. You write builder code — ordinary JavaScript that runs once and appends operations to a Circuit. Handwired's own docs state that no tool converts existing JavaScript source into a program.

Does Handwired need training?

No. The weights are written by hand by builder code, so the program is exact from the start. You can optionally unfreeze numbers kept in cells and train them with the program's own gradients.

Is it really exact?

Yes, within its declared contracts. emitCompare returns bits equal to JavaScript's comparison for every FP32 value in the operands' declared ranges; selects at an exact 0 or 1 return the chosen operand exactly. Some helpers, like division and square root, are approximate and documented with error bounds.

How is it differentiable if it makes exact decisions?

Sums, products, selects and ReLUs all have gradients. Exact decisions are steps with zero slope, so gradients are useful for continuous values such as positions, sizes, coefficients and table entries.

Does Handwired need a GPU or WebGPU?

No. The runtime evaluates programs in JavaScript on the CPU. Only the JSON search demo compiles its programs to WebGPU shaders to search 100,000 documents in parallel.

How do I install Handwired?

It isn't on npm. Clone github.com/chenglou/handwired and run bun install, or add it to a bundler project as a pinned git dependency, e.g. "handwired": "github:chenglou/handwired#", and import its TypeScript sources.

What demos exist?

The official handwired README has Mini OS (a small desktop with 9,909 weights in 130 layers), the Learned gallery (a photo layout whose coefficients train in real time) and a JSON search over 100,000 documents on WebGPU. This site adds interactive demos for soft switches, exact comparisons, circuit graphs and training.
