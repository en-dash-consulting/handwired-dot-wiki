About handwired.wiki

handwired.wiki is an independent learning resource and demo gallery for Handwired, built by En Dash Consulting. It is not affiliated with or endorsed by Cheng Lou.

Who made Handwired?

Cheng Lou created Handwired. The source is at github.com/chenglou/handwired under the MIT license (© 2026 Cheng Lou). Please star the repo and read the upstream docs — they are the authoritative reference.

Who runs this site?

En Dash Consulting, which also runs learn-pretext.com and html-in-canvas.dev. The site's source is public at github.com/en-dash-consulting/handwired-dot-wiki; corrections and new demos are welcome as issues or pull requests.

How do the demos use Handwired?

The demos import Handwired's runtime (src/runtime/numeric-ui-core.ts) and template from a commit-pinned git dependency and call only its public functions. Explanations paraphrase or quote upstream's README and docs; figures are from upstream READMEs at that commit.

Where can I learn more?

  • chenglou.me/handwired — official demos
  • Upstream docs — tutorial, expressions, patterns, execution model
